# Internet Topology Zoo subset (held-out zero-shot test set)

Source: S. Knight, H. X. Nguyen, N. Falkner, R. Bowden, M. Roughan,
"The Internet Topology Zoo", IEEE JSAC 29(9), 2011. https://github.com/sk2/topologyzoo

One topology per network family, 10-60 nodes, at least 3 independent cycles.
These graphs are NEVER used for training the zero-shot GNN.
